# 模型分组介绍

| 分组名称 | 来源/原理 | 优点  | 缺点  | 典型特性 |
|------|-------|-----|-----|------|
| **default 分组** | 逆向各类官方网页模型 | 价格极低（如 ChatGPT-4o 不到官方 10%），具备网页模型能力：实时检索、图文混合 | 稳定性受供应影响；不支持 tools | 实时检索、图文生成、网页风格回答 |
| **原价分组** | 直接来自大模型企业官方 API | 稳定性极高（99.99%），速度快且可靠 | 价格约为官方 98%，成本较 default 高 | 等同官方 API，适合作为"兜底"使用 |
| **原生分组** | 企业特惠 API 来源 | 性能上与原价分组一致，速度快 | 特惠渠道供应可能不稳定；未来可能取消 | 与原价性能相同 |
| **ClaudeCode / Codex 分组** | 逆向 ClaudeCode 与 Codex coding 工具 | 价格低廉，同时支持 tools | 逆向来源导致稳定性可能不如原价分组 | 支持 Tools，适合代码/自动化类任务 |

### 站点模型分组现状总结

由于历史原因，站点的模型分组较为混杂，目前采用以下分类逻辑：


1. **default 分组（最早期逆向模型）**
   * **优势**：极具性价比；具备网页模型的多模态能力，如实时检索、图文混合答复。
   * **劣势**：不支持 tools；官方GPU供不应求时，可能会被祭天导致稳定性受影响。
2. **原价分组（官方 API 正规渠道）**
   * **优势**：官方直连，稳定性达 99.99%，速度快。
   * **劣势**：价格接近官方（约 98%，deepseek 为 66%），成本高于 default 分组。
   * **用途**：适合作为稳定兜底方案。
3. **原生分组（企业特惠 API）**
   * **特点**：性能等同原价分组。
   * **问题**：供应量受企业优惠情况影响，可能会缩减或取消。
4. **ClaudeCode / Codex 分组**
   * **来源**：逆向 ClaudeCode 或 Codex 工具。
   * **特点**：价格便宜且支持 tools，适合代码和自动化任务。
