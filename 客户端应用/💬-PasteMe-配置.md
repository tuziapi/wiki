# 💬 PasteMe 配置

PasteMe


1. 地址：https://github.com/CKylinMC/PasteMe
2. 介绍： 一个剪贴板工具，可以让你通过AI辅助你复制和粘贴。原本是一直在等PowerToys的AdvancedPaste的自定义端点功能，但是苦等这么久也没出，干脆自己试着做一个。
3. 基本功能： a. 按下快捷键（默认 Ctrl+Shift+V）呼出面板 b. 面板将显示当前剪贴板内容的预览 c. 选择需要的功能： ○ 统计：查看文本的字符数、行数等统计信息 ○ 编辑：直接修改剪贴板内容 ○ 转为纯文本：清除格式，保留纯文本
4. AI 功能 \n● 需要先在设置中启用 AI 功能并配置 API Key。 \n● 转为 JSON：AI 将帮你把内容转换为 JSON 格式 \n● 询问 AI：让 AI 分析或解答关于剪贴板内容的问题 \n● AI 创作：基于剪贴板内容，让 AI 继续创作
5. 搭配兔子 API 调用 LLM \n● 点击地址，进入发布页，点击选择下载的版本，进行下载安装 ![](https://pic1.imgdb.cn/item/67c137b1d0e0a243d407c567.png) ![](https://pic1.imgdb.cn/item/67c137b2d0e0a243d407c568.png) ● 打开软件，在首页点击 AI 设置 ![](https://pic1.imgdb.cn/item/67c137b2d0e0a243d407c56a.png) ● 填写兔子 API 地址，以及 APIKEY ![](https://pic1.imgdb.cn/item/67c137b1d0e0a243d407c566.png) ● 下拉，可选择使用联网功能，填写密钥 ![](https://pic1.imgdb.cn/item/67c137cad0e0a243d407c57d.png) ● 即可正常使用 AI 功能 ![](https://pic1.imgdb.cn/item/67c137cad0e0a243d407c57f.png) 这样可以在复制内容时，直接查询剪贴板上不懂的东西，连浏览器都不用打开了。 ![](https://pic1.imgdb.cn/item/67c137cbd0e0a243d407c581.webp) 同时PasteMe！提供了自定义AI描述的功能，这样就可以把想要AI处理的格式提前设定好，像是回复评论，自动优化内容等等。 ![](https://pic1.imgdb.cn/item/67c137cad0e0a243d407c57b.webp)
