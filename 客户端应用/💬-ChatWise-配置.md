# 💬 ChatWise 配置

1. 地址：https://chatwise.app/
2. 介绍：ChatWise是一款使用Rust开发、支持离线工作、广泛兼容OpenAI、Anthropic等多种AI平台API、提供多模态处理，包括文本、PDF、音频和图像、文本转语音等功能的AI聊天本地客户端。目前支持macOS和Windows，移动应用即将推出。

## 搭配兔子 API 使用 LLM


1. 访问网页下载客户端并安装 ![chatwise-6.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/chatwise-6.png)
2. 安装完毕后，在左下角打开设置

   ![chatwise-5.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/chatwise-5.png)
3. 在设置中选择模型后，点击左下角加号，在弹出菜单中选择OpenAI Compatible ![chatwise-4.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/chatwise-6.png)
4. 添加兔子 API。如图所示填写API名字、API Base URL、API Key后，点击Fetch可以获取到兔子API支持的所有模型，你也可以根据需要自行添加或删除这里的模型

API-KEY获取步骤：

* 访问官方API平台：[api.tu-zi.com](https://api.tu-zi.com/)
* 登录后进入密钥管理面板创建API-KEY
* 在钱包内完成充值（新用户有0.4美金赠送）

> 📌 详细说明可参考：[兔子自带的nextchat配置说明](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/zh/Chat/nextchat)

 ![chatwise-3.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/chatwise-5.png)


5. 保存完毕后关闭设置，即可在上方选择模型后展开正常对话

 ![chatwise-2.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/chatwise-2.png)

 ![chatwise-1.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/chatwise-1.png)
