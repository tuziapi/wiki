# 💬 ChatHub 配置

ChatHub


1. 地址： 官方地址：https://chathub.gg 开源地址：https://github.com/chathub-dev/chathub 第三方地址：https://www.crxsoso.com/webstore/detail/iaakpnchhognanibcahlpcplchdfmgma
2. 介绍： ChatHub 是款全能聊天机器人客户端，在一个应用中使用不同的聊天机器人，目前支持 ChatGPT、Bing Chat、Google Bard、Claude、讯飞星火、ChatGLM、Alpaca 和 Vicuna，之后还将集成更多机器人
3. 特点： 同时与多个聊天机器人聊天，方便比较它们的答案 支持 ChatGPT API 模式，比 ChatGPT Plus 更快、更省成本 在使用 ChatGPT API 模式时，可以查看令牌使用统计信息 快捷方式，可以快速在浏览器中的任何位置激活应用程序 支持 Markdown 和代码高亮显示 自定义提示和社区提示的 Prompt 库 本地保存对话历史记录 导入和导出所有数据 将对话分享为 Markdown 暗黑模式
4. 通过兔子 API 调用 LLM \n● 通过第三方地址下载，点击右侧下载按钮 ![](https://pic1.imgdb.cn/item/67bee4add0e0a243d40609dd.png) ● 选择 CRX 格式的文件，点击下载 ![](https://pic1.imgdb.cn/item/67bee4add0e0a243d40609de.png) ● 右键点击浏览器的拓展按钮，选择管理拓展 ![](https://pic1.imgdb.cn/item/67bee4add0e0a243d40609df.png) ● 打开拓展的开发者模式 ![](https://pic1.imgdb.cn/item/67bee4acd0e0a243d40609db.png) ● 将下载好的 CRX 文件拖进浏览器的拓展页面中 ![](https://pic1.imgdb.cn/item/67bee4d1d0e0a243d40609f9.png) ● 安装完毕后，自动会打开 ![](https://pic1.imgdb.cn/item/67bee4d1d0e0a243d40609fa.png) ● 首页选择通过 API key 使用，点击 OpenAI 的配置 ![](https://pic1.imgdb.cn/item/67bee4d2d0e0a243d40609fb.png) ● 使用兔子 API 的 API key 和 API 地址进行配置，并打开按钮 ![](https://pic1.imgdb.cn/item/67bee4d0d0e0a243d40609f8.png) ![](https://pic1.imgdb.cn/item/67bee522d0e0a243d4060a35.png) **API-KEY获取步骤** 访问官方API平台：[api.tu-zi.com](https://api.tu-zi.com) 登录后进入密钥管理面板创建API-KEY 在钱包内完成充值（新用户有0.4美金赠送） 📌 详细说明可参考：[兔子自带的nextchat配置说明](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/zh/Chat/nextchat)
