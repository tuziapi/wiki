# Happy 使用教程 - 手机操控 Claude Code / Codex

## 📱 什么是 Happy？

Happy 是一个让你可以**用手机远程控制电脑上的 Claude Code 或 Codex** 的工具。


---

## 🚀 快速上手（3 步搞定）

### 第一步：在电脑上安装 Happy CLI

#### 前置要求

* 已经安装了 Node.js（如果没有，先去 [nodejs.org](https://nodejs.org) 下载安装）
* 已经安装了 Claude Code 或 Codex

#### 安装命令

打开**终端**（Mac）或**命令提示符**（Windows），输入：

```bash
npm install -g happy-coder
```

等待安装完成即可。

### 第三步：连接手机和电脑

#### 1. 在电脑上启动 Happy

打开终端，根据你想使用的工具输入对应命令：

**如果使用 Claude Code：**

```bash

```

**如果使用 Codex：**

```bash
happy codex
```

#### 2. 选择连接方式

执行命令后会出现选项，选择 **Mobile**（移动端）

## 🎯 开始使用

连接成功后，你就可以在手机上：

* 📝 **发送指令**给 Claude Code（就像在电脑上使用一样）
* 👀 **实时查看** AI 的工作进度和生成的代码
* 🔔 **接收通知**（当 AI 需要权限或遇到错误时）

### 示例操作

在手机 App 中输入：

```
创建一个 hello world 的 HTML 文件
```

Claude Code 会在你的电脑上执行，你可以在手机上看到整个过程！


---

## ⚡ 设备切换

### 从手机切回电脑控制

在电脑的终端窗口中**按任意键**，就会立即切换回电脑控制。

### 从电脑切回手机控制

Happy 会自动检测，当你在手机上操作时，控制权会转移到手机。

## ❓ 常见问题

### Q1: 安装 happy-coder 时提示权限错误？

**解决方案：** 使用管理员权限安装

**Mac/Linux:**

```bash
sudo npm install -g happy-coder
```

**Windows:** 以管理员身份运行命令提示符


---

### Q2: 二维码扫描后连接失败？

**检查清单：**


1. 确保手机和电脑都连接到网络（不需要同一 WiFi）
2. 检查电脑防火墙是否拦截了 Happy
3. 尝试重启 Happy 和 App，重新扫码


---

### Q3: 手机 App 显示"连接已断开"？

**原因：** 电脑上的 Happy 进程可能已关闭

**解决：** 返回电脑终端，重新运行 `happy` 或 `happy codex`
