# 🤖 AI Workspace 配置

AI as Workspace


1. 地址：https://github.com/NitroRCr/AIaW
2. 介绍：更好的 AI 客户端，支持多平台，多服务商
3. 特点： \n● 全平台一致体验 ○ 支持平台：Windows, Linux, Mac OS, Android, Web (PWA) ○ 多服务商支持：OpenAI, Anthropic, Google, DeepSeek, xAI, Azure 等 \n● 对话页面 ○ 用户输入预览 ○ 修改提问、重新生成 以分叉的形式呈现 ○ 自定义键盘快捷键 ○ 对齐到消息开头/结尾的快速滚动 ![](https://pic1.imgdb.cn/item/67ccf3d8066befcec6e1741c.webp) ● 多工作区 ○ 创建多个工作区，将不同主题的对话分隔开 ○ 可将多个工作区放入一个文件夹中；支持嵌套 ○ 一个工作区中可创建多个助手，也可以创建全局助手 ![](https://pic1.imgdb.cn/item/67ccf3d8066befcec6e1741d.png) ● 数据储存 ○ 数据首先储存在本地，无需加载且离线可浏览 ○ 登录后可使用云同步，跨设备实时同步 ○ 多窗口协同支持：同一浏览器打开多个标签，数据响应式同步 \n● 细节设计 ○ 支持将文本类型文件（代码、csv等）作为附件，AI 能看到文件内容和文件名；避免文件内容占据显示空间 ○ 对于大段的文本，可在输入框外使用 Ctrl + V 粘贴，也将作为附件；避免大段内容占据显示空间 ![](https://pic1.imgdb.cn/item/67ccf3da066befcec6e1741e.webp) ○ 可在用户输入中引用先前消息中的内容，方便对助手回答的部分内容针对性地追问 ○ 选中多行消息文本后，可直接复制 Markdown 原文 ![](https://pic1.imgdb.cn/item/67ccf3d4066befcec6e1741b.webp) ○ 粘贴从 VSCode 复制的代码时，自动用代码块包裹，并标明语言 ![](https://pic1.imgdb.cn/item/67ccf407066befcec6e17426.webp) ● MCP 协议 ○ 支持 MCP Tools, Prompts, Resources ○ 支持 STDIO 和 SSE 两种连接方式 ○ 可在插件市场安装 MCP 类型插件，或者手动添加 MCP 服务器 ● Artifacts ○ 可将助手回答的任意部分转为 Artifacts ○ 用户可编辑，带版本控制，代码高亮 ○ 可控制助手对 Artifacts 的读写权限 ○ 可同时打开多个 Artifacts ![](https://pic1.imgdb.cn/item/67ccf408066befcec6e17427.webp) ● 插件系统 ○ 内置计算器、文档解析、视频解析、图像生成等插件 ○ 可在插件市场安装更多插件 ○ 可将 Gradio 应用配置为插件；兼容部分 LobeChat 插件； ○ 插件不只是工具调用 ![](https://pic1.imgdb.cn/item/67ccf406066befcec6e17423.png) ● 轻量，高性能 ○ 启动迅速，无需等待 ○ 切换对话丝滑流畅 ![](https://pic1.imgdb.cn/item/67ccf407066befcec6e17425.webp) ● 动态提示词 ○ 通过创建提示词变量，使用模板语法，构建动态可复用的提示词 ○ 抽离提示词中的重复部分，放入工作区变量，实现提示词的复用 ![](https://pic1.imgdb.cn/item/67ccf441066befcec6e17433.png)
4. 使用兔子 API 调用 LLM ● 点击进入 AI as Workspace 的 GitHub 页面，点击进入下载页面，选择合适的版本进行下载 ![](https://pic1.imgdb.cn/item/67ccf45b066befcec6e17438.png) ![](https://pic1.imgdb.cn/item/67ccf45b066befcec6e17439.png) ● 安装完毕后，进入首页，先点击登录，登录之后可在多平台进行数据同步 登录不需要害怕，是以发送验证码的形式进行登录，而非创建用户密码 ![](https://pic1.imgdb.cn/item/67ccf45c066befcec6e1743a.png) ● 登录完毕以后，点击页面左下方设置按钮 ![](https://pic1.imgdb.cn/item/67ccf45b066befcec6e17437.png) ● 进行服务商和系统助手的 LLM 自定义功能，填写兔子 API 及其相关配置 ![](https://pic1.imgdb.cn/item/67ccf483066befcec6e17440.png) API-KEY获取步骤 访问官方API平台：api.tu-zi.com 登录后进入密钥管理面板创建API-KEY 在钱包内完成充值（新用户有0.4美金赠送） 📌 详细说明可参考：兔子自带的nextchat配置说明 ● 即可正常使用 ![](https://pic1.imgdb.cn/item/67ccf484066befcec6e17441.png) ● 新出的客户端，功能挺丰富的，账户同步功能仅支持 30 天试用，希望能出 webdav 功能 ![](https://pic1.imgdb.cn/item/67ccf483066befcec6e1743f.png)
