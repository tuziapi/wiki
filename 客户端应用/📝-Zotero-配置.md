# 📝 Zotero 配置

1. 地址：https://www.zotero.org/
2. 介绍 Zotero 是一个开源、易用的多平台科研工具，可用来帮助收集、组织、引用、分享各类资料，注册账号之后可以使用官方服务器在多端自动同步以及使用浏览器插件，还可以直接在网页中操作。
3. 搭配兔子 API 使用 LLM ● 在首页点击 download 选择合适的版本进行下载 ![](https://pic1.imgdb.cn/item/67bdb27bd0e0a243d4056445.png) ● 搭配 PDF 阅读插件 zotero-gpt 下载地址：https://github.com/MuiseDestiny/zotero-gpt/releases 进入地址后，点击进行下载 ![](https://pic1.imgdb.cn/item/67bdb27cd0e0a243d4056449.png) ● 搭配 PDF 翻译插件 zotero-pdf-translate 下载链接：https://github.com/windingwind/zotero-pdf-translate/releases 进入地址后，点击进行下载 ![](https://pic1.imgdb.cn/item/67bdb27dd0e0a243d4056451.png) ● 打开 Zotero 后，点击上方工具选择插件 ![](https://pic1.imgdb.cn/item/67bdb27bd0e0a243d4056441.png) ● 进入后点击齿轮图标，选择 install，导入下载的 XPI 文件 ![](https://pic1.imgdb.cn/item/67bdb2eed0e0a243d405673e.png) ● 安装完毕后，进行更新检查 ![](https://pic1.imgdb.cn/item/67bdb2eed0e0a243d4056741.png) ● 返回主页，点击上方编辑，选择设置 ![](https://pic1.imgdb.cn/item/67bdb2efd0e0a243d4056746.png) ● 点击翻译，填写兔子 API 密钥，和相关配置 ![](https://pic1.imgdb.cn/item/67bdb2eed0e0a243d405673b.png) ![](https://pic1.imgdb.cn/item/67bdb317d0e0a243d4056835.png) ● 点击 GPT，填写兔子 API 密钥，和相关配置 ![](https://pic1.imgdb.cn/item/67bdb317d0e0a243d4056837.png) API-KEY获取步骤

* 访问官方API平台：[api.tu-zi.com](https://api.tu-zi.com)
* 登录后进入密钥管理面板创建API-KEY
* 在钱包内完成充值（新用户有0.4美金赠送）

> 📌 详细说明可参考：[兔子自带的nextchat配置说明](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/zh/Chat/nextchat)

● 配置完成后，即可进行 Zotero 的大模型操作     ![](https://pic1.imgdb.cn/item/67bdb318d0e0a243d4056839.png)
