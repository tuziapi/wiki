# 💬 LobeHub 配置

配置教程适用于LobeChat Cloud和自部署版本


1. 地址：https://github.com/lobehub/lobe-chat
2. 介绍：打造你的个人 AI 助手和专业团队，与 AI 携手推进你的创意事业、写作项目、学习征途和职业任务。从此，指挥一个专门的小组来应对特定挑战，提升工作效率，在个体崛起的时代中脱颖而出。
3. 搭配兔子 API 使用 AI大模型 3.1 进入设置中心 ![pasted_image_20250517001332.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/lobechat/pasted_image_20250517001332.png) 3.2 进入`AI服务商`页面并`创建自定义AI服务商`，填写`服务商ID`、`服务商名称`、`代理地址`、`API Key`，然后点击`新建` ![pasted_image_20250517001854.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/lobechat/pasted_image_20250517001854.png) **API-KEY获取步骤** 访问官方API平台：[api.tu-zi.com](https://api.tu-zi.com) 登录后进入密钥管理面板创建API-KEY 在钱包内完成充值（新用户有0.4美金赠送） 📌 详细说明可参考：[兔子自带的nextchat配置说明](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/zh/Chat/nextchat) 3.3 切换到刚创建的兔子API，点击`获取模型列表`，按需启用模型 ![pasted_image_20250517002907.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/lobechat/pasted_image_20250517002907.png) ![pasted_image_20250517003049.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/lobechat/pasted_image_20250517003049.png) 3.4回到聊天窗口选择模型就可以和AI聊天了 ![pasted_image_20250517003547.png](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/lobechat/pasted_image_20250517003547.png)
