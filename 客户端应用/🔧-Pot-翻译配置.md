# 🔧 Pot 翻译配置

1. 地址：https://pot-app.com/
2. 介绍： 一个跨平台的划词翻译和OCR软件，支持划词翻译、输入翻译、外部调用、剪切板监听模式、截图 OCR、截图翻译等多种特色功能 具体介绍 https://github.com/pot-app/pot-desktop
3. 搭配兔子 API 使用 LLM ● 进入首页点击下载，选择合适的版本，进行安装 ● 安装完毕之后，不会出现任何界面，点击任务栏右边的三角 ![](https://pic1.imgdb.cn/item/67bd82bed0e0a243d4050586.webp) ● 右键 pot，选择偏好设置 ![](https://pic1.imgdb.cn/item/67bd82bed0e0a243d4050589.webp) ● 选择服务设置 ![](https://pic1.imgdb.cn/item/67bd82bfd0e0a243d405058a.webp) ● 点击添加内置服务 ![](https://pic1.imgdb.cn/item/67bd82bed0e0a243d4050585.webp) ● 下拉选择 OpenAI ![](https://pic1.imgdb.cn/item/67bd82ead0e0a243d4050638.webp) ● 填写 API 的相关配置，选择模型 ![](https://pic1.imgdb.cn/item/67bd82ead0e0a243d405063b.webp) API-KEY获取步骤

* 访问官方API平台：[api.tu-zi.com](https://api.tu-zi.com)
* 登录后进入密钥管理面板创建API-KEY
* 在钱包内完成充值（新用户有0.4美金赠送）

> 📌 详细说明可参考：[兔子自带的nextchat配置说明](https://wiki.tu-zi.com/zh/Chat/nextchat)

● 下拉保存  ![](https://pic1.imgdb.cn/item/67bd82ebd0e0a243d405063e.webp) ● 即可正常使用 Pot 的相关服务  ![](https://pic1.imgdb.cn/item/67bd82ebd0e0a243d4050640.webp)
