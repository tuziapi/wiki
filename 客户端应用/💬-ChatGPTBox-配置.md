# 💬 ChatGPTBox 配置

1. 地址：https://github.com/josStorer/chatGPTBox
2. 介绍：这个扩展程序不收集你的数据, 你可以通过对代码全局搜索 fetch( 和 XMLHttpRequest( 找到所有的网络请求调用. 代码量不多, 所以很容易验证.
3. 特点： \n● 🌈 在任何页面随时呼出聊天对话框 (Ctrl+B) \n● 📱 支持手机等移动设备 \n● 📓 通过右键菜单总结任意页面 (Alt+B) \n● 📖 独立对话页面 (Ctrl+Shift+H) \n● 🔗 多种API支持 (免费用户和Plus用户可用Web API, 此外还有GPT-3.5, GPT-4, Claude, NewBing, Moonshot, 自托管支持, Azure等) \n● 📦 对各种常用网站的集成适配 (Reddit, Quora, YouTube, GitHub, GitLab, StackOverflow, Zhihu, Bilibili) (受到wimdenherder启发) \n● 🔍 对所有主流搜索引擎的适配, 并支持自定义查询以支持额外的站点 \n● 🧰 框选工具与右键菜单, 执行各种你的需求, 如翻译, 总结, 润色, 情感分析, 段落划分, 代码解释, 问询 \n● 🗂️ 静态卡片支持浮出聊天框, 进行多分支对话 \n● 🖨️ 随意保存你的完整对话记录, 或进行局部复制 \n● 🎨 强大的渲染支持, 不论是代码高亮, 还是复杂数学公式 \n● 🌍 多语言偏好支持 \n● 📝 自定义API地址支持 \n● ⚙️ 所有站点适配与工具均可自由开关, 随时停用你不需要的模块 \n● 💡 工具与站点适配开发易于扩展, 对于开发人员易于自定义, 请查看开发&贡献部分 \n● 😉 此外, 如果回答有任何不足, 直接聊天解决!
4. 使用兔子 API 调用 LLM ● 点击网站，点击按钮进入到选择版本下载的页面 ![](https://pic1.imgdb.cn/item/67c97d88066befcec6df1c0e.png) ● 选择合适的版本进行下载 ![](https://pic1.imgdb.cn/item/67c97d88066befcec6df1c0f.png) ● 右键点击浏览器的拓展按钮，选择管理拓展 ![](https://pic1.imgdb.cn/item/67c97d88066befcec6df1c10.png) ● 打开拓展的开发者模式 ![](https://pic1.imgdb.cn/item/67c97d88066befcec6df1c10.png) ● 将下载好的 CRX 文件拖进浏览器的拓展页面中 ![](https://pic1.imgdb.cn/item/67bee4acd0e0a243d40609db.png) ● 点击浏览器的拓展按钮，可以看见安装成功的 ChatGPTBox ![](https://pic1.imgdb.cn/item/67c97da0066befcec6df1c12.png) ● 点击打开，选择模块，新建 ![](https://pic1.imgdb.cn/item/67c97da0066befcec6df1c13.png) ● 选择兔子 API 进行 LLM 的配置 ![](https://pic1.imgdb.cn/item/67c97da0066befcec6df1c14.png) ● 然后把其他的 API 模式的对勾取消掉，仅保存兔子 API ![](https://pic1.imgdb.cn/item/67c97da0066befcec6df1c11.png) ● 回到常规设置，设置触发模式，选择 API 模式，即可正常使用 ![](https://pic1.imgdb.cn/item/67c97dba066befcec6df1c17.png) ![](https://pic1.imgdb.cn/item/67c97dba066befcec6df1c16.png)
