# 💬 ChatBox 配置

1. 地址：https://chatboxai.app/zh
2. 介绍： Chatbox AI 是一款 AI 客户端应用和智能助手，支持众多先进的 AI 模型和 API，可在 Windows、MacOS、Android、iOS、Linux 和网页版上使用。
3. 搭配兔子 API 使用 LLM ● 进入首页点击免费下载，安装到想要的位置 ![](https://pic1.imgdb.cn/item/67bd842bd0e0a243d40509e2.webp) ● 安装完毕后，打开右下角的设置 ![](https://pic1.imgdb.cn/item/67bd842cd0e0a243d40509e3.webp) ● 选择模型提供方，添加自定义提供方 ![](https://pic1.imgdb.cn/item/67bd842cd0e0a243d40509e5.webp) ● 添加兔子 API，设置相关配置 ![](https://pic1.imgdb.cn/item/67bd842dd0e0a243d40509e6.webp) API-KEY获取步骤

* 访问官方API平台：[api.tu-zi.com](https://api.tu-zi.com)
* 登录后进入密钥管理面板创建API-KEY
* 在钱包内完成充值（新用户有0.4美金赠送）
