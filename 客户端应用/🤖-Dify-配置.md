# 🤖 Dify 配置

### 以claude-3-5-sonnet-20240620 模型接入为例


1. 访问 [api.tu-zi.com](http://api.tu-zi.com) 注册账户后，您可以访问钱包查看余额并进行余额充值 ![1.webp](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/dify/1.webp)
2. 点击令牌，生成你的令牌为后续调用大模型使用；令牌即常说的API-KEY ![2.webp](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/dify/2.webp) ![3.webp](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/dify/3.webp)
3. 复制好你的令牌，前往dify.ai进入设置页面，配置自定义模型 ![4.webp](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/dify/4.webp)
4. 模型名称：`claude-3-5-sonnet-20240620` ； API key：`你复制的令牌`  ； API URL：`<https://api.tu-zi.com/v1>` ![5.webp](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/dify/5.webp)
5. 在你创建的工作流中，选择自定义的模型 ![6.webp](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/dify/6.webp)
