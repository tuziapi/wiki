# 📝 思源笔记 配置

1. 地址：https://b3log.org/siyuan/
2. 介绍：思源笔记是一款隐私优先的个人知识管理系统，支持细粒度块级引用和 Markdown 所见即所得。
3. 特性： 大部分功能是免费的，即使是在商业环境下使用。 \n● 内容块 ○ 块级引用和双向链接 ○ 自定义属性 ○ SQL 查询嵌入 ○ 协议 siyuan:// \n● 编辑器 ○ Block 风格 ○ Markdown 所见即所得 ○ 列表大纲 ○ 块缩放聚焦 ○ 百万字大文档编辑 ○ 数学公式、图表、流程图、甘特图、时序图、五线谱等 ○ 网页剪藏 ○ PDF 标注双链 \n● 导出 ○ 块引用和嵌入块 ○ 带 assets 文件夹的标准 Markdown ○ PDF、Word 和 HTML ○ 复制到微信公众号、知乎和语雀 \n● 数据库 ○ 表格视图 \n● 闪卡间隔重复 \n● 接入 OpenAI 接口支持人工智能写作和问答聊天 \n● Tesseract OCR \n● 模板片段 \n● JavaScript/CSS 代码片段 \n● Android/iOS/鸿蒙 App \n● Docker 部署 \n● API \n● 社区集市
