# 🌐 NextChat 在线版

## 以`claude-3-5-sonnet-20240620`为案例


1. 访问 [api.tu-zi.com](http://api.tu-zi.com) 注册账户后，您可以访问钱包查看余额并进行余额充值

 ![](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/nextchat/1.png)


2. 点击令牌，生成你的令牌为后续调用大模型使用；令牌即常说的API-KEY

 ![](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/nextchat/2.png)

 ![](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/nextchat/3.png)


3. 进入聊天界面进行配置，填入接口地址`[https://api.tu-zi.com](https://api.tu-zi.com/)`和上面选择的令牌

 ![](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/nextchat/4.png)

 ![](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/chat/nextchat/5.png)


4. 如果是非openai的模型，需要在自定义模型名中加入`claude-3-5-sonnet-20240620` +`@OpenAI` =`claude-3-5-sonnet-20240620@OpenAI`

 ![](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/nextchat-2.png)


5. 新建对话选择自定义的模型`claude-3-5-sonnet-20240620@OpenAI`即可交流

 ![](https://sydney-ai.notion.site/image/https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F14a93052-6a43-4e3f-a1bd-fddf8b26c810%2F5bc6b396-6cc1-44f4-9c1a-f67dba535906%2Fimage.png?table=block&id=cce29553-1802-4006-b43b-22afb0a0618e&spaceId=14a93052-6a43-4e3f-a1bd-fddf8b26c810&width=2000&userId=&cache=v2)

 ![](https://tuziai.oss-cn-shenzhen.aliyuncs.com/wiki/nextchat-1.png)
