# 20260311_买了gaccode会员，如何在原版Claudecod

## 问题

买了 gaccode会员，如何在原版 Claudecode 中使用。

## 回答

安装官方原版 Claude Code 后，用 gaccode 账户获取 API Key，设置 `ANTHROPIC_API_KEY` 和 `ANTHROPIC_BASE_URL=https://gaccode.com/claudecode`，再把 Key 后 20 位加入 `~/.claude.json` 的 approved 列表即可使用。
