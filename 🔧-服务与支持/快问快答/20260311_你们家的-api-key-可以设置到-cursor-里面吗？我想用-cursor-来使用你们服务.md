## 问题

你们家的 api key 可以设置到 cursor 里面吗？我想用 cursor 来使用你们服务

## 回答

可以。Cursor 里可直接填兔子 API Key，`Override OpenAI Base URL` 设为 `[https://api.tu-zi.com/v1](https://api.tu-zi.com/v1，验证通过后即可使用。)`[，验证通过后即可使用。](https://api.tu-zi.com/v1，验证通过后即可使用。)

但「新版 cursor 已经不支持外接第三方的 Claude 模型，以及不支持外接第三方的模型跑 agent 模型」
