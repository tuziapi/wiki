# 20260311_gaccode的月卡怎么用

## 问题

gaccode的月卡怎么用

## 回答

gaccode 月卡是一种包月订阅方案，购买后可以使用 Claude Code、Codex 和 Gemini CLI 三个工具，积分通用扣除，免翻墙，不封号。

### 第一步：注册 gaccode 账户

使用邀请链接注册，可获得 1 万积分赠送：

https://gaccode.com/signup?ref=4WZILH6T

### 第二步：购买月卡兑换码

前往兔小店购买订阅兑换码：https://store.tu-zi.com

### 第三步：激活订阅

回到 https://gaccode.com 账户页面，输入兑换码激活订阅。

### 第四步：选择使用方式

激活后有两种使用方式：

**方案A：改版客户端（推荐新手）**

安装即用，无需配置，免翻墙：

```bash
npm install -g https://gaccode.com/claudecode/install --registry=https://registry.npmmirror.com
```

安装后进入项目目录，运行 `claude` 启动，按提示在浏览器完成 gaccode 账户绑定即可。

**方案B：官方原版 + API Key（适合高级用户）**


1. 安装官方原版：

```bash
npm install -g @anthropic-ai/claude-code
```


2. 在 gaccode 账户页面获取 API Key，配置环境变量：

```bash
export ANTHROPIC_API_KEY=你的gaccode_api_key
export ANTHROPIC_BASE_URL=https://gaccode.com/claudecode
```


3. 运行 `claude` 启动使用。

* 积分在 Claude Code、Codex、Gemini CLI 三个工具中通用扣除

* 邀请好友可获得额外积分奖励
