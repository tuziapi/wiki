# 20260311_我家的 api key 可以设置到 cursor 里面吗？我想用

## 问题

我家的 api key 可以设置到 cursor 里面吗？我想用 cursor 来使用你们服务

## 回答

可以，Cursor 支持填写兔子 API Key 使用服务；在设置里填入 API Key，并将 Base URL 设为 `https://api.tu-zi.com/v1` 后验证即可。
