### 第三步：开始创作

登录成功后，您可以充分使用平台的协作功能：

#### ✏️ 创建新文档

* 在草稿箱点击"新建文档"按钮
* 开始编写您的内容

#### 📝 编辑现有文档

* 浏览**共创审核区**找到需要完善的内容
* 点击进入文档直接编辑
* 补充信息、修正错误或优化表达

#### 🔍 版本管理

* 所有修改都会自动保存
* 完整的版本历史可随时查看
* 支持回滚到任意历史版本

#### 💬 实时协作

* 多人可同时编辑同一文档
* 实时看到其他编辑者的光标位置
* 在线状态显示，避免编辑冲突
* 支持文档内评论和讨论


---

### 第四步：提交与发布

完成内容创作后：


1. **检查内容**
   * 确保信息准确完整
   * 检查格式和排版
   * 添加必要的链接和引用
2. **提交审核**
   * 您的文档发布在**共创审核区**会自动进入审核流程
   * 审核团队会检查内容质量
3. **获得反馈**
   * 通过后文档正式发布
   * 优质内容将获得相应奖励

## 🎯 创作建议

### 内容质量

* 确保信息准确性和时效性
* 使用清晰的结构和标题层级
* 适当添加示例和说明

### 格式规范

* 使用Markdown格式编写
* 合理使用标题、列表、引用等元素
* 添加必要的图片和链接

### 协作礼仪

* 尊重他人的编辑成果
* 重大修改前可先在评论区讨论
* 保持友好的沟通态度

## ❓ 常见问题

**Q: 我没有Slack账号怎么办？** A: 请联系管理员，会协助您完成Slack账号的注册和加入。

**Q: 登录后看不到编辑按钮？** A: 可能是权限配置需要时间生效，请稍等或联系管理员确认。

**Q: 我的编辑内容丢失了？** A: Outline有自动保存和版本历史功能，可以从历史记录中恢复内容。

**Q: 如何联系其他协作者？** A: 可以通过文档评论功能或Slack工作空间进行沟通。
