## 1.1 Claude Code使用方案

### 方案A：改版Claude Code客户端详细步骤

> ⚠️ **重要说明：** 改版会自动适配路径，主要解决线路稳定性问题，请放心使用。

#### A.1 安装改版Claude Code客户端

```bash
npm install -g https://gaccode.com/claudecode/install --registry=https://registry.npmmirror.com
```

#### A.2 启动与登录

> ⚠️ **网络问题解决：** 如果遇到与cc链接的网络问题，请执行 `claude --pick-relay` 切换线路试下

```bash
# 进入项目目录
cd your-project-folder

# 启动 Claude Code

claude
```

**浏览器登录并绑定账户：**


1. **注册账户** - 使用邀请链接注册gaccode账户
2. **复制绑定地址** - 复制窗口中的绑定地址到浏览器中
3. **完成绑定** - 点击授权完成绑定

> 🤖 **模型选择：** • 默认模型：**Claude 4.5** • 可切换至 **Claude 4 Opus**，在设置中关闭强制Claude 4 然后输入 `/model` 切换

#### A.3 其他配置

此方式无需额外配置，安装后即可直接使用。

## 1.2 Codex 安装与使用

> ✨ **好消息：** 现在您的gaccode订阅可以同时用于OpenAI Codex！积分在Claude Code和Codex之间通用扣除。

**前置条件**

使用Codex建议安装 Node.js 18 或更高版本，并保持系统包管理器更新至最新稳定版。

```bash
# 验证Node.js版本
node --version

npm --version
```

### 方案A：一键安装启动（推荐）

适合想要快速上手的同学，自动完成程序下载、登录与配置。

#### A.1 安装 Codex（gaccode 版）

运行以下命令全局安装：

```bash
npm install -g https://gaccode.com/codex/install
```

#### A.2 启动与自动登录

安装完成后，运行：

```bash
codex
```

首次运行会自动：

* 🔄 **程序下载：** 自动下载必要的程序文件
* 🔐 **OAuth 登录：** 打开浏览器完成 gaccode 账户登录
* ⚙️ **自动配置：** 完成 API 配置与环境设置

> 🎯 **简单易用：** 只需运行 `codex`，无需手动配置任何环境变量。


---

### 方案B：官方 Codex 客户端 + gaccode API

适合希望使用官方 Codex 客户端的同学，通过配置自定义模型提供商对接 gaccode API。

```bash
# 全局安装
npm i -g @openai/codex

# 验证安装
codex --version
```

#### B.1 配置 `~/.codex/config.toml`

新增 `gac` 配置并将默认 `profile` 指向它：

```toml

profile = "gac"

[model_providers.gac]
name = "gac"
base_url = "https://gaccode.com/codex/v1"
wire_api = "responses"
env_key = "CODEX_API_KEY"

[profiles.gac]
model_provider = "gac"
model = "gpt-5.5"
model_reasoning_effort = "medium"
approval_policy = "on-request"
```

#### B.2 设置环境变量

在 Shell （命令窗口）中导入从 订单中 获取的 API Key，Mac/Windows 可能不同，可以问下 AI 如何配置（我的操作系统是\*\*\*，我需要配置永久环境变量CODEX_API_KEY="你的Key字符串"，请协助我）：

```bash
# 到此页面获取 API Key
# https://gaccode.com/api-keys

export CODEX_API_KEY="你的Key字符串"
```

#### B.3 启动官方 Codex

直接运行官方客户端，使用 `gac` 配置档：

```bash
codex
```

> **提示：** 如你在 `config.toml` 中未将 `profile` 设为 `gac`，也可通过命令行切换：`codex --profile gac`。

> **说明：** 采用官方 Codex + API Key 方式通常无需浏览器授权，直接使用即可。

**故障排除**

* **连接问题：** 检查防火墙、代理或网络设置

## 1.3 Gemini CLI 安装和使用

### 方案A: 改版 Gemini CLI 客户端详细步骤


**Gemini CLI 安装**

通过 npm 安装 Gemini CLI，开始使用 AI 进行编程。

**前置条件**

> **Node.js**
>
> Gemini CLI 需要 Node.js 18 或更高版本。


**安装步骤**

> 
> 1. **安装 Node.js**
>
> 从官方网站下载并安装 Node.js。
>
> 官网地址: <https://nodejs.org/en/download/>
>
> 验证安装：

```javascript
# 验证安装
node --version
npm --version
```


> 
> 2. **安装 Gemini CLI**
>
> 运行以下命令全局安装 Gemini CLI：

```javascript
npm install -g https://gaccode.com/gemini/install
```

该命令会从配置的源下载并安装程序包。

> 
> 3. 运行 Gemini CLI
>
> 运行以下命令进入Gemini CLI ：

```javascript
gemini
```


> **模型切换** 
>
> 模型切换 您可以覆盖默认模型（gemini-2.5-pro）以使用不同的 Gemini 模型：
>
> 例如：使用 gemini-3-pro-preview     在进来gemini cli 之前 执行
>
> ```javascript
> gemini --set-model gemini-3-pro-preview
> ```
>
> **清除模型覆盖（使用默认）**
>
> ```javascript
> gemini --set-model
> ```
>
> 模型覆盖保存在 \~/.gemini/model_override 文件中，会在会话之间保持。


> **静默模式** 
>

>
> 设置环境变量
>
> ```javascript
> export GEMINI_LAUNCHER_QUIET=1
> ```
>
> 启动 Gemini CLI
>
> ```javascript
> gemini 
> ```
>
> 这将提供更简洁、更安静的体验，类似于官方 Gemini CLI 客户端。
