## 步骤2: 获取GAC Code登录令牌

### 2.1 登录GAC Code网站


1. 打开浏览器，访问 <https://gaccode.com>
2. 使用您的账户登录

### 2.2 打开开发者工具

按下键盘上的 **F12** 键打开开发者工具。

**其他打开方式**：

* Windows/Linux: 按 `F12` 键
* Mac: 按 `Cmd + Option + I`
* 或右键点击页面 → 选择"检查"或"审查元素"

浏览器窗口会弹出一个新的面板，这就是"开发者工具"。

### 2.3 监控网络请求


1. **切换到Network（网络）标签**
   * 在开发者工具顶部有一排选项卡（Elements、Console、Sources、**Network**...）
   * 点击 **Network**（网络）选项卡
2. **确保网络监控已开启**
   * 查看是否有记录按钮（通常是圆形按钮）
   * 如果按钮是红色或显示正在记录，表示已开启
   * 如果未开启，点击按钮启用网络监控
3. **筛选请求（可选但推荐）**
   * 点击网络请求列表上方的 **XHR** 或 **Fetch** 按钮进行筛选
   * 或在搜索框内输入 `/me` 快速定位

### 2.4 触发请求并查找数据


1. **刷新页面触发网络请求**
   * 保持开发者工具开启
   * 按 **F5** 刷新当前页面
   * 或点击网站上的任意功能来产生网络活动
2. **找到** `**me**` **请求**
   * 在网络请求列表中，查找名为 **me** 的请求
   * 类型通常是 `fetch` 或 `XHR`
   * 点击该请求

### 2.5 复制Token


1. **查看请求详情**
   * 点击 `me` 请求后，右侧会显示详细信息窗口
   * 点击 **Headers**（标头）选项卡
2. **找到Authorization字段**
   * 在 **Request Headers**（请求标头）区域中
   * 找到名为 **Authorization** 的字段
   * 该字段的值格式为：`Bearer Xc...0B8{...xq`（一长串字符）
3. **复制Token值**
   * **只复制** `Bearer ` **后面**的那串字符
   * **不要**复制 `Bearer` 单词本身
   * **不要**复制 `Bearer` 后面的空格
   * 复制完整的令牌字符串（通常很长）

### 2.6 ⚠️ 重要：验证令牌格式

**正确的令牌格式示例**：

```
Xc...0B8{...xq
```

这是一长串无规律的字符串，通常包含字母、数字和特殊字符。

**❌ 错误的格式（不要使用）**：

```
Bearer Xc...0B8{...xq
```

**检查要点**：

* ✅ 令牌是一长串字符（通常很长）
* ❌ **不要**包含 `Bearer ` 前缀
* ❌ **不要**包含引号或其他符号
* ✅ 只复制Authorization字段中 `Bearer ` 后面的部分

**总结**：

* 从浏览器复制的内容：`Bearer Xc...0B8{...xq`
* 应该保存到配置的内容：`Xc...0B8{...xq`（去掉Bearer和空格）

## 步骤3: 配置项目

### 3.1 定位配置文件

配置文件位置：

```
data/config/config.json
```

如果文件不存在，从模板创建：

```bash

cp data/config/config.json.template data/config/config.json
```

### 3.2 编辑配置文件

使用您喜欢的编辑器打开配置文件：

```bash
# 使用nano编辑器
nano data/config/config.json

# 或使用vim

vim data/config/config.json

# 或使用VS Code

找到 data/config/config.json
```

### 3.3 填入登录令牌

找到 `gaccode` 平台配置部分：

```json
{
  "platforms": {
    "gaccode": {
      "name": "GAC Code",
      "api_base_url": "https://relay05.gaccode.com/claudecode",
      "api_key": "",
      "login_token": "",          // 👈 在这里粘贴您的JWT令牌
      "model": "",
      "small_model": "",
      "enabled": true
    }
  }
}
```

**修改为**：

```json
{
  "platforms": {
    "gaccode": {
      "name": "GAC Code",
      "api_base_url": "https://relay05.gaccode.com/claudecode",
      "api_key": "",
      "login_token": "Xc...0B8{...xq",  // 👈 粘贴您从Network请求中复制的Token（不含Bearer）
      "model": "",
      "small_model": "",
      "enabled": true
    }
  }
}
```

**⚠️ 关键提醒**：

* ✅ 令牌是一长串字符（从Network → me请求 → Headers → Authorization中复制）
* ❌ **不包含** `Bearer ` 前缀（只复制Bearer后面的部分）
* ✅ 令牌两端用双引号包围
* ✅ 确保JSON格式正确（注意逗号）

### 3.4 保存配置

* **nano**: 按 `Ctrl+X`，然后按 `Y`，最后按 `Enter`
* **vim**: 按 `Esc`，输入 `:wq`，按 `Enter`
* **VS Code**: 按 `Cmd+S` (Mac) 或 `Ctrl+S` (Windows/Linux)

### 3.5 验证配置格式

```bash
# 验证JSON格式是否正确
python3 -c "import json; json.load(open('data/config/config.json')); print('✓ 配置文件格式正确')"

# 验证login_token是否已配置
python3 -c "
import json

config = json.load(open('data/config/config.json'))
token = config['platforms']['gaccode']['login_token']
if token and not token.startswith('Bearer'):
    print('✓ login_token配置正确')
    print(f'  Token长度: {len(token)} 字符')
elif token and token.startswith('Bearer'):
    print('✗ 错误：token包含Bearer前缀，请删除Bearer和空格')
    print('  示例：Bearer Xc... → Xc...')
else:
    print('✗ 错误：token未配置')
"
```

## 步骤4: 集成到Claude Code

根据您的操作系统选择对应的配置方法：


---

### 🍎 Mac版本配置

#### 4.1 定位Claude Code配置文件

Mac系统配置文件位置：

```
~/.claude/settings.json
```

完整路径：`/Users/您的用户名/.claude/settings.json`

#### 4.2 检查配置文件是否存在

```bash
# 检查配置文件
ls -la ~/.claude/settings.json

# 如果提示"No such file or directory"，说明文件不存在，需要创建
```

#### 4.3 获取项目完整路径

```bash
# 在项目目录中执行
cd /path/to/gaccode-statusline

pwd

# 输出示例: /Users/yourname/projects/gaccode-statusline
# 复制这个路径，下一步会用到
```

#### 4.4 创建或编辑配置文件

```bash
# 使用nano编辑器创建/编辑配置文件
nano ~/.claude/settings.json

# 或使用vim

vim ~/.claude/settings.json

# 或使用VS Code

code ~/.claude/settings.json
```

#### 4.5 添加statusLine配置

将以下内容添加到配置文件中（**替换项目路径为步骤4.3中获取的路径**）：

```json
{
  "statusLine": {
    "type": "command",
    "command": "python3 /Users/yourname/projects/gaccode-statusline/statusline.py",
    "refreshInterval": 1000
  }
}
```

**⚠️ 重要提醒**：

* 将 `/Users/yourname/projects/gaccode-statusline` 替换为您在步骤4.3中获取的实际路径
* 使用 `python3` 命令（Mac默认使用python3）
* 路径必须是**绝对路径**，不能使用 `~` 或相对路径

**完整配置示例**：

如果您的 `settings.json` 已有其他配置，添加statusLine部分：

```json
{
  "otherSettings": "...",
  "statusLine": {
    "type": "command",
    "command": "python3 /Users/yourname/projects/gaccode-statusline/statusline.py",
    "refreshInterval": 1000
  }
}
```

#### 4.6 保存配置文件

* **nano**: 按 `Ctrl+X`，然后按 `Y`，最后按 `Enter`
* **vim**: 按 `Esc`，输入 `:wq`，按 `Enter`
* **VS Code**: 按 `Cmd+S`

#### 4.7 验证配置格式

```bash
# 验证settings.json格式
python3 -m json.tool ~/.claude/settings.json

# 如果配置正确，会输出格式化后的JSON
# 如果有错误，会提示具体的JSON格式问题
```

## 常见问题

### ❓ 问题1: 看到消费但看不到余额

**症状**：

```
Model:Claude-3.5-Sonnet Time:21:20:47 Cost:$0.23 Git:main
                                                  ^^ 缺少GAC.B余额信息
```

**可能原因**：


1. `login_token` 未配置或配置错误
2. Token包含 `Bearer ` 前缀
3. Token已过期

#### 🍎 Mac解决方法

```bash
# 1. 检查token配置
cd /path/to/gaccode-statusline

python3 -c "
import json

config = json.load(open('data/config/config.json'))
token = config['platforms']['gaccode']['login_token']
print('Token已配置:', bool(token))
print('Token长度:', len(token) if token else 0)
print('包含Bearer前缀:', token.startswith('Bearer') if token else False)
"

# 2. 查看API调用日志
tail -20 data/logs/gaccode-platform.log | grep -E "(401|Unauthorized|ERROR)"

# 3. 如果看到401错误，说明token无效或格式错误
```

#### 🪟 Windows解决方法

**PowerShell**：

```powershell
# 1. 检查token配置
cd D:\path\to\gaccode-statusline

python -c "
import json

config = json.load(open('data/config/config.json'))
token = config['platforms']['gaccode']['login_token']
print('Token已配置:', bool(token))
print('Token长度:', len(token) if token else 0)
print('包含Bearer前缀:', token.startswith('Bearer') if token else False)
"

# 2. 查看API调用日志
Select-String -Path data\logs\gaccode-platform.log -Pattern "401|Unauthorized|ERROR" | Select-Object -Last 20
```

**CMD**：

```cmd
# 1. 进入项目目录
```

### ❓ 问题3: Token格式错误

**错误示例**：

```json
// ❌ 错误1: 包含Bearer前缀
"login_token": "Bearer Xc...0B8{...xq"

// ❌ 错误2: 包含引号
"login_token": "\"Xc...0B8{...xq\""

// ❌ 错误3: 多行分割
"login_token": "Xc...0B8
{...xq"
```

**正确格式**：

```json
// ✅ 正确：只包含Bearer后面的token字符串
"login_token": "Xc...0B8{...xq"
```

**Token来源说明**：

* 浏览器Network中看到的：`Authorization: Bearer Xc...0B8{...xq`
* 应该复制并配置的部分：`Xc...0B8{...xq`（**不含** `Bearer ` 前缀）

**自动修复Bearer前缀**：

#### 🍎 Mac版本

```bash

cd /path/to/gaccode-statusline

python3 << 'EOF'
import json

config_file = 'data/config/config.json'
config = json.load(open(config_file))
token = config['platforms']['gaccode']['login_token']

if token.startswith('Bearer '):
    fixed = token.replace('Bearer ', '', 1)
    config['platforms']['gaccode']['login_token'] = fixed
    with open(config_file, 'w') as f:
        json.dump(config, f, indent=2)
    print('✓ Bearer前缀已自动移除')
else:
    print('✓ Token格式正确')
EOF
```

#### 🪟 Windows版本

**PowerShell**：

```powershell

cd D:\path\to\gaccode-statusline

python -c @"
import json

config_file = 'data/config/config.json'
config = json.load(open(config_file))
token = config['platforms']['gaccode']['login_token']

if token.startswith('Bearer '):
    fixed = token.replace('Bearer ', '', 1)
    config['platforms']['gaccode']['login_token'] = fixed
    with open(config_file, 'w') as f:
        json.dump(config, f, indent=2)
    print('✓ Bearer前缀已自动移除')
else:
    print('✓ Token格式正确')
"@
```

**CMD（创建临时Python脚本）**：

### ❓ 问题5: Token过期

JWT令牌有时效性，过期后需要重新获取。

**症状**：

* 之前能显示余额，现在突然不显示了
* 日志显示 401 Unauthorized

**解决方法**：


1. 重新登录GAC Code网站
2. 按照步骤2重新获取JWT令牌
3. 更新 `config.json` 中的 `login_token`
4. 重启Claude Code

## 🔐 安全提醒

### 保护您的令牌


1. **不要分享配置文件**
   * `config.json` 包含您的登录令牌
   * `.gitignore` 已自动排除此文件
2. **检查.gitignore**

   ```bash
   # 确认这些文件被忽略
   cat .gitignore | grep config.json
   # 应该看到: data/config/config.json
   ```
3. **定期更新令牌**
   * JWT令牌会过期
   * 建议每月更新一次
4. **日志安全**
   * 日志会自动掩码敏感信息
   * 查看日志时，令牌显示为 `***`
